## 🛍️ Global Retail Company Analytics

## ⚙️ Tools Used
- Microsoft Excel
- Looker Studio / Data Studio

## 📝 Project Overview
Global retail company analytics is an analytics dashboard based on the company’s sales data to improve operational efficiency and customer satisfaction. The company faces challenges in understanding sales trends, optimizing product inventory, and developing effective marketing strategies. The dashboard provides insights into sales performance, customer behavior, and product trends to support data-driven decision-making.

## 📊 Dataset Used
- Raw data: raw data from RevoU
- Clean data: https://github.com/afifahasfaa/global_retail_company_analytics/blob/main/Sales_Data.xlsx

## 💡 What I learned
- How to clean data using Microsoft Excel
- How to summarize KPIs using scorecard
- How to visualize insight using chart
- How to add drop-down filter

## ❔ Question 
1.	Which year had the highest total sales?
2.	Which country has the highest sales of Classic Cars throughout 2004?
3.	Which product line was sold the most (in quantity) throughout September 2003 to March 2004?
